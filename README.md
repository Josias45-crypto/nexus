# NEXUS

Cerebro personal 100% local que empieza vacío y acumula conocimiento día a día
(texto, audio y, más adelante, imágenes). Corre en Docker.

## Principios
- Guardar siempre el original; lo derivado se puede regenerar.
- El modelo es intercambiable por configuración.
- Un módulo por cada sentido.
